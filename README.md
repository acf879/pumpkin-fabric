# pumpkinmc-fabric

An attempt to make fabric mods work out of the box for Pumpkin-MC.

**_Below is the repo of the fabric-loader that is being ported to Pumpkin MC_**

`https://github.com/FabricMC/fabric-loader/tree/master?tab=readme-ov-file`

I am not affiliated with the pumpkin mc dev team as
I am just a fan of their work in recreating a fast java addition
server. With the v1.0.0 release I want to attempt to make a port
of pumpkin that accepts fabric mods

I am planning on using the C-ABI as it is extremely stable and is compatible
with the majority of programming languages
